# Eval dataset schema (JSONL, one chunk per line)

```jsonc
{
  "session_id": "s07_saas_renewal",
  "chunk_id": "s07_c04",
  "timestamp_ms": 1760000004000,          // monotonic within a session
  "speaker": "counterpart",               // candidate | counterpart
  "text": "Sure, a 30% uplift is totally reasonable for a product that went down twice last quarter.",
  "acoustic_metadata": { "pitch_volatility": 0.71, "speech_rate_wpm": 142, "pause_duration_ms": 900, "volume_intensity": 0.38 },

  "expected_sentiment": "sarcastic",
  "acceptable_sentiments": ["sarcastic", "negative"],   // lenient scoring
  "expected_risk": "high",                               // ordinal; MAE reported
  "expected_volatility": false,
  "tags": ["contradiction:text-pos/meaning-neg", "pricing", "context-dependent"],
  "pair_id": null,                                       // set for counterfactual pairs
  "rationale": "Positive surface words contradict the outage reference; long pause + elevated pitch vs. this speaker's baseline."
}
```

Rules
- Sessions are replayed **in order**; context matters. Each file = one split (`tune.jsonl`, `holdout.jsonl`).
- Labels are written **before** the model is run on them; label edits need a rationale + PROMPT_CHANGELOG note.
- Coverage matrix is regenerated by `run-eval.ts` and printed at the top of every report.
- `fixtures/sample-chunk.json` = one valid request body used by smoke tests and `/ship`.
