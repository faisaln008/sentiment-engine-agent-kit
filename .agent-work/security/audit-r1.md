## Passed checks

1. Secrets: `git grep` and `git log -p --all` for `gsk_|AIza|sk-|csk-|api_key=|Bearer <token>` return nothing; untracked files clean; dotenv files ignored (`!.env.example`), never in history; `.env.example` has names only; reports/raw/*.jsonl and serverlog-*.jsonl contain no keys, no request text, no provider bodies (ids, provider, outcome only).
2. Brief text: no distinctive brief sentences in tracked files (15 phrases checked, incl. the sample payload text and its sample mitigation). Skills/tests use differently worded mitigations. `docs/assignment/` is ignored and never in history.
3. Logging: every call checked. info: `chunk` (ids, provider, latency, outcome, reason), `llm attempt failed`, warm-up; warn: no keys, unknown speaker (ids), breaker/disabled; error: err name/message only. Verified with `app.inject`: neither text nor path appears in logs. Request logging disabled.
4. Limits: bodyLimit 32 KB (413 verified), id max 512, maxParamLength 6144, text sliced to MAX_TEXT_CHARS before prompt, context turns clipped to 40 words/240 chars, WS inbound maxPayload 1 KB, outbound frame cap 16 KB, WS_MAX_CLIENTS 50 (close 1013), 1 MB buffered-amount drop, 30 s ping/pong heartbeat, MAX_SESSIONS LRU plus TTL sweep (unref'd), records 200, top moments 3.
5. ReDoS: lexicon alternations are word-bounded with bounded gaps (`{0,80}`, `{0,40}`, `{0,20}`); pathological 2000-char inputs (repeated "either ", "sign by friday xxx", "sorry", etc.) all under 1 ms (worst 0.92 ms).
6. Injection structure: 12 payloads (plain, fake `>>>`/`TEXT <<<`, fullwidth brackets, ZWSP/soft-hyphen/tag chars, nested `<<<<<<`, CR/LS/PS newlines, fake JSON verdict, context-turn injection): none produced an extra delimiter or an extra prompt line; the user block is 2 lines (CURRENT + TEXT), context turns defanged and clipped. Output side: JSON slice + enum mapping + `TelemetryResponseSchema.parse` + truncation; parse failure falls to the heuristic, endpoint stays 200 (verified for hostile enum values, oversized intent, HTML in mitigation).
7. CORS: exact-match allow-list, `*` filtered out, no ACAO for other origins (OPTIONS from evil origin -> 404, no header), `Vary: Origin`. HTTP without Origin is allowed (non-browser clients). WS without or with a foreign Origin -> closed 1008 (see S-01: not authentication).
8. Error bodies: 400 `invalid_request` with generic messages, no text/id echo (verified), 413 `payload_too_large`, 500 `internal_error`; LLM failures never reach 5xx (analyzeChunk catch plus emergency path; verified).
9. Frontend: grep for dangerouslySetInnerHTML, innerHTML, eval, new Function is empty; LLM strings render as React text nodes (`title=` attribute only); class names built from enum-validated sentiment; frames re-validated with ServerMessageSchema and size-checked. No `import.meta.env`/`VITE_` use in src (`VITE_API_TARGET` read only in vite.config.ts, node side). No dist built, so no bundle to grep.
10. Deps: prod `npm audit` 0. Runtime deps fastify, zod, undici, ws each justified in commit messages (37ea100 for ws; 070e52b / ADR-005 for undici); no install scripts in any package.json.
11. Agent guardrails: `.claude/settings.json` denies Read/Edit/Write of the dotenv files, pushes, publish, destructive rm; PreToolUse hooks (guard-bash blocked my own dotenv mention, guard-secrets) plus lint/typecheck hooks exist. Informational: deny rules cover the root dotenv path only; the hook is the real defence.
