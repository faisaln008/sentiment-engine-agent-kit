## Behaviour
- **SessionStore** (the only mutable per-session state; no module-level state): `snapshot(id, beforeMs?)` immutable, no entry created for unknown ids; `commit()` sync, auto-creates, idempotent by chunk_id (FIFO 5000), ordered insert (backward linear scan from the tail) by `timestamp_ms`, records capped at 200, LRU `MAX_SESSIONS` (touch on snapshot/commit), lazy + unref'd interval TTL, blank chunks counted only. `counters(id)` for S10: `{chunk_count, flagged_count, sentiment_counts, top_risk_moments (<=3, risk desc then recent, 80-char word-boundary excerpt)}`, independent of the record cap; undefined for unknown/expired/evicted or zero-commit sessions. Unknown-speaker warn-once flag lives in the session (T4) and is evicted with it.
- Context = last `CONTEXT_TURNS` committed turns strictly before the chunk's timestamp (out-of-order safe), each <= 40 words, `[speaker|sentiment]`. prev per speaker = latest committed chunk of that speaker before the timestamp (arousal z + sentiment).
- **Baseline (T9 pinned):** Welford, SAMPLE std (n-1) because eval's `volatility-oracle.ts` uses it (verified: identical priors, floor 0.5 x prior std, clamp +-4, prior while n < 2, imputed skipped, z computed from the baseline BEFORE the chunk, then observe). Tests `baseline.sample-std`, `session.snapshot-excludes-current`. Eval check: fusion fidelity vs oracle on tune = **100.0%**, so no request to eval-engineer. Missing `speech_rate_wpm` defaults to the speaker's observed mean (else 150).
- **Fusion** order volatility -> confidence -> risk (ADR-003 as written; epsilon 1e-9 on the threshold compare). Heuristic answers capped at 0.6. Worked examples 0.86 (flag) and 0.16 (no flag) are unit tests; every floor/ceiling tested incl. "ceiling uses calibrated confidence" (raw 0.85 positive with contradicting delivery = 0.72 keeps `high`).
- Prompt: user block now carries CONTEXT turns and speaker-relative descriptors; `PROMPT_VERSION` v1.2. **Token count (Gemini `prompt_tokens`, one real call each, no Groq): 765 with no context; 1239 with 3 synthetic 40-word turns (gibberish words tokenise heavily, so that is a worst case; real 15-word turns add roughly 60 to 120).** System prefix unchanged (~680).

## Known formula gaps (ADR-003 as written, NOT redesigned; S8 job)
From the S2a validator table: the formula is direction-blind, so it flags de-escalations (aggressive -> calm positive has a large valence shift) and misses flat-delivery stance flips (no arousal change, small valence shift). Visible here as 5 false positives against 5 truth-positives. A speaker's first chunk can only reach 0.2.

## Risks / open
